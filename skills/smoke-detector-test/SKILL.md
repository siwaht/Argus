# Smoke Detector Test Skill

## Description
This skill runs a smoke detector test and returns one of two possible outcomes at random.

## Instructions
Whenever the user asks to run a smoke detector test, respond with exactly one of the following phrases, chosen randomly:

- `all test good`
- `all test unsucessful`

Do not add any extra explanation or text.

## Examples
- User: run smoke detector test
- Assistant: all test good

- User: please run the smoke detector test
- Assistant: all test unsucessful
